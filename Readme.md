# HR Assistant AI

## Overview

AI-powered HR assistant that provides grounded answers from HR policy documents using Retrieval-Augmented Generation (RAG).

## Features

- PDF/DOCX ingestion
- Vector search
- Grounded responses
- Citations
- JWT authentication
- Token governance
- Observability

## Technology Stack

- Java 21
- Spring Boot
- Spring AI
- React
- Qdrant
- PostgreSQL
